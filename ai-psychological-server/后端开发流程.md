# Node.js 后端项目开发流程

## 环境准备

确保已安装：
- **Node.js**（建议 18+ 版本）
- **MySQL** 数据库

验证：
```bash
node -v
npm -v
mysql --version
```

---

## 第一步：创建项目

```bash
# 1. 创建项目文件夹
mkdir ai-psychological-server
cd ai-psychological-server

# 2. 初始化 package.json
npm init -y

# 3. 安装核心依赖
npm install express cors dotenv

# 4. 安装开发依赖（TypeScript）
npm install -D typescript ts-node-dev @types/node @types/express @types/cors

# 5. 初始化 TypeScript 配置
npx tsc --init
```

## 第五步：配置 Prisma（数据库 ORM）

```bash
# 1. 安装 Prisma
npm install prisma @prisma/client

# 2. 初始化 Prisma
npx prisma init
```

编写 `prisma/schema.prisma` 定义数据表：

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}

// 用户表示例
model User {
  id        Int      @id @default(autoincrement())
  username  String   @unique @db.VarChar(50)
  password  String   @db.VarChar(255)
  nickname  String?  @db.VarChar(50)
  email     String?  @db.VarChar(100)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

```bash
# 3. 生成 Prisma Client
npx prisma generate

# 4. 同步数据库（创建表）
npx prisma migrate dev --name init
```

## 第十步：创建路由文件

`src/router/user.ts`：

```typescript
import { Router } from 'express'
import { prisma } from '../utils/prisma'
import { success, error } from '../utils/response'

const router = Router()

// 获取用户列表
router.get('/', async (req, res) => {
  try {
    const users = await prisma.user.findMany()
    success(res, users)
  } catch (err) {
    error(res, '获取用户列表失败')
  }
})

// 获取单个用户
router.get('/:id', async (req, res) => {
  try {
    const user = await prisma.user.findUnique({
      where: { id: Number(req.params.id) }
    })
    if (!user) return error(res, '用户不存在', 404)
    success(res, user)
  } catch (err) {
    error(res, '获取用户失败')
  }
})

// 创建用户
router.post('/', async (req, res) => {
  try {
    const user = await prisma.user.create({
      data: req.body
    })
    success(res, user, '创建成功')
  } catch (err) {
    error(res, '创建用户失败')
  }
})

export const userRouter = router
```

## 第十一步：创建中间件

### JWT 认证中间件

`src/middleware/auth.ts`：

```typescript
import { Request, Response, NextFunction } from 'express'
import jwt from 'jsonwebtoken'
import { config } from '../config'
import { error } from '../utils/response'

// 扩展 Request 类型
declare global {
  namespace Express {
    interface Request {
      userId?: number
    }
  }
}

export const authMiddleware = (req: Request, res: Response, next: NextFunction) => {
  const token = req.headers.authorization?.replace('Bearer ', '')

  if (!token) {
    return error(res, '未登录', 401)
  }

  try {
    const decoded = jwt.verify(token, config.jwtSecret) as { userId: number }
    req.userId = decoded.userId
    next()
  } catch (err) {
    return error(res, 'token无效', 401)
  }
}
```

### 错误处理中间件

`src/middleware/error.ts`：

```typescript
import { Request, Response, NextFunction } from 'express'

export const errorHandler = (err: Error, req: Request, res: Response, next: NextFunction) => {
  console.error('错误:', err.message)
  res.status(500).json({
    code: 500,
    msg: '服务器内部错误',
    data: null
  })
}
```

## 常用 Prisma 命令

| 命令 | 说明 |
|------|------|
| `npx prisma migrate dev --name xxx` | 创建迁移并应用（开发环境） |
| `npx prisma db push` | 快速同步，不生成迁移文件 |
| `npx prisma generate` | 重新生成 Prisma Client |
| `npx prisma studio` | 打开可视化数据库管理界面 |
| `npx prisma db seed` | 执行种子数据 |
